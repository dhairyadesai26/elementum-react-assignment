## 🌟 Project Overview

**Elementum** is a modern and visually appealing creative agency landing page built with **React.js** and **Vite**.

The project focuses on:

* 🎨 Clean and elegant UI design
* ⚡ Fast performance with Vite
* 📱 Fully responsive layouts
* 🧩 Reusable React components
* 🎯 Modern frontend development practices
* 💡 Pixel-perfect implementation inspired by the provided design reference

The website presents a fictional creative agency that emphasizes innovation, strategy, digital experiences, and impactful design solutions.

## ⚡ Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/elementum-react-assignment.git
```

### 2️⃣ Navigate to Project

```bash
cd elementum-react-assignment
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

### 5️⃣ Open Browser

```bash
http://localhost:5173
```
